# GOAL 106 후속 — punct 후보 58건 검토표

**교정 대상 0건.** 구두점 차이는 의미를 바꾸지 않으며, 확인 결과 전부
프로젝트 규약이거나 PDF 추출 아티팩트 또는 정렬 어긋남이었다.

| 분류 | 건수 | 내용 |
|---|---:|---|
| PDF추출 | 8 | `,` ↔ `.` 는 저해상도 추출에서 흔한 혼동. 의미 무영향 |
| 규약 | 25 | 청원 도입부 콜론(`залбирцгаая:`). 파서가 콜론에 의존하는 구조 — 데이터가 맞다 |
| 정렬 | 9 | PDF 쪽이 여는 따옴표 — 인용 경계 어긋남 |
| PDF중복 | 5 | PDF 가 `Н..` 처럼 마침표를 중복 출력 — 추출 아티팩트 |
| (기각) | 11 | 데이터 형태가 PDF 에도 존재 — 차이가 아님 |

## 대표 사례

```
규약    데이터 `Уудлагын дуулал: х.28`  ↔ PDF `Уудлагын дуулал, х.28.`
        → PRD FR-160-B 가 콜론 형식을 명시. 데이터가 맞다.

규약    데이터 `…гуйн залбирцгаая:`      ↔ PDF `…гуйн залбирцгаая.`
        → 청원 도입부 콜론. 파서가 의존하는 구조.

PDF중복 데이터 `Та зардас Н.-ийг`        ↔ PDF `Та зардас Н..-ийг`
        → PDF 가 마침표를 중복 출력.

PDF추출 데이터 `…хайрлаж,биднийг`        ↔ PDF `…хайрлаж.биднийг`
        → `,`/`.` 는 추출에서 흔히 혼동된다. 의미 무영향.
```
