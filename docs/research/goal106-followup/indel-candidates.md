# GOAL 106 후속 — indel 후보 검토표 (29건 → 고유 22종)

자동 판정으로 확정된 것은 **"데이터가 PDF 와 다르다"** 까지다. 공통 근거는
각 건 모두 PDF 두 뷰(기하 복원 / `full_pdf.txt` SoT)가 **일치**하고 데이터 형태는
두 뷰 어디에도 **0회**라는 것이다.

다만 `psalter-texts.json` 계열은 extractor 산출물 위에 캐논티클·#42 수동교정이
누적된 **큐레이트 자산**이다. PDF 와 다르다고 데이터가 틀렸다는 뜻이 아니며,
역으로 PDF 쪽 추출이 깨진 경우(9·12·21번)도 실제로 섞여 있다.
**어느 쪽이 옳은지는 몽골어 어형 판단이 필요하다 — 미교정 상태로 둔다.**
