# 따옴표-대문자 phrase 병합 37건 판정 (2026-08-08)

`regroupPhrasesByCapitalStart` 의 `^[А-ЯЁӨҮ]` 는 여는 따옴표를 못 넘긴다.
그래서 `“Энэ хүн ба тэр хүн…` 같은 행이 **앞 시행에 붙어 한 줄로 렌더**됐다.
`docs/bug-reports/2026-08-08-split-psalm-part2-missing.md` §파생 발견에서
"전부 결함은 아닐 수 있다" 고 유보했던 37건을 여기서 전수 판정한다.

**결론: 37건 전부 분리가 옳다.**

## 처음 세운 기준은 틀렸다

"책은 단 폭을 넘는 시행만 접으므로, 접힘이면 앞 행이 단 오른쪽 끝까지 차 있다"
는 기하 규칙을 세우고 32건을 분리 대상으로 판정했다. 그런데 `calibrate.py` 로
**확실한 접힘**(기존 phrase 안에서 소문자로 시작하는 연속행 — 새 시행일 수
없다)의 분포를 재 보니:

```
확실한 접힘 (소문자 연속행)      : n=277  중앙 55.1pt  90% 129.6pt
확실한 별개 시행 (phrase 첫 행)  : n=239  중앙 75.7pt  90% 124.4pt
```

두 분포가 거의 겹친다. 이 책은 단 끝에서 접는 조판이 아니라 **시행을 편집자가
나눠 앉힌** 판본이고, 앞 행 여유는 판별력이 없다. 규칙을 폐기했다.
(`adjudicate.py` 는 케이스 수집·위치 특정만 하고 `gap` 은 이 반증의 기록으로 남긴다.)

## 실제 판별 신호

인쇄면을 직접 보면 규약이 드러난다 (`crops/*.png`):

```
Дайснууд минь намайг муулан              ← 기준 들여쓰기, 대문자 = 시행
“Тэр хэзээ үхэж,                         ← 기준 들여쓰기, 대문자 = 시행
      нэр нь үгүй болох вэ?” гэж ярилцав. ← 들여쓰기 + 소문자 = 접힘
```

**접힘 = 들여쓰기 + 소문자 시작.** 대문자는 따옴표 뒤에 있어도 새 시행이다.
즉 `regroupPhrasesByCapitalStart` 의 판단 자체는 옳고, 정규식이 따옴표를
못 넘긴 것만 문제다.

## 독립 교차 검증 — plain 저장본

`psalter-texts.json` 의 `stanzas[]` 는 rich 와 별도로 큐레이트된 시행 목록이다.
37건 중:

| plain 의 상태 | 건수 |
|---|---|
| 따옴표 행을 **독립 항목**으로 보유 | 32 |
| 앞 행과 **병합**해 보유 | **0** |
| 따옴표 행 + 뒤따르는 소문자 접힘행을 묶어 보유 | 5 |

병합해 둔 건이 하나도 없다. 나머지 5건도 같은 자리에서 끊되 뒤 접힘행만
붙인 형태라, 분리 방향은 37건 전부 일치한다.

## 기계적 검증

`apply-split.mjs` 는 "rich phrase 결합 결과 == plain stanzas" 인 블록 수를
적용 전후로 비교한다:

```
phrases 보유 블록 330
plain 과 완전 일치: 적용 전 213 → 적용 후 236 (+23)
분리된 블록 29, 새로 생긴 phrase 37
회귀(일치→불일치): 없음
```

**회귀 0** — 이전에 plain 과 일치하던 블록을 하나도 깨지 않으면서 23개 블록이
새로 일치한다. `lines` · `paragraphBoundaries` · `source` 는 손대지 않았다
(파싱 대조로 확인, 바뀐 것은 29개 블록의 `phrases` 뿐).

남은 94개 불일치 블록은 따옴표와 무관한 별개 원인이다 — 이번 범위 밖.

시작하고 소문자 접힘행만 붙었다. 인쇄면과 일치. 콘솔 에러 없음.

## 남은 리스크

`splitAtQuotedCapitals` 는 `^[“"„«]\s*[А-ЯЁӨҮ]` 로 끊는다. 인용이 **소문자로**
시작하면 여전히 앞 시행에 붙는데, 그건 실제로 접힘일 가능성이 높아 의도된
동작이다. 향후 `build-phrases-into-rich.mjs` 의 정규식 자체를 고치려면 이
폴더의 캘리브레이션과 plain 교차검증을 회귀 기준으로 쓸 것.
