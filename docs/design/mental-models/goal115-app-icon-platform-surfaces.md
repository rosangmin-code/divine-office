# MM — 앱 아이콘 플랫폼 표면 모델 (g-52 / GOAL 115)

## 표면 3종과 소비자

| 표면 | 파일 | 소비자 | 제약 |
|---|---|---|---|
| 브라우저 탭 파비콘 | `src/app/icon.svg` (Next app-router 규약 → `/icon.svg`) | 데스크톱/모바일 브라우저 탭 | 투명 허용, 16–32px 가독성 필요 |
| iOS 홈 화면 (A2HS) | `src/app/apple-icon.png` (180×180) | iOS Safari 홈 화면 추가 | **투명 미지원 — 투명 픽셀은 검정으로 채워짐**. 불투명 PNG 필수 |
| Android 홈 화면 (PWA) | `manifest.ts` → `/icon.svg` `purpose: any` + `maskable` | Android 런처 | **maskable은 원형/스쿼클로 크롭** — 핵심 요소는 중앙 80% 안전 영역(safe zone) 안에, full-bleed 배경 필수 |

`public/icon.svg` · `public/apple-icon.png` 는 동일 자산의 서빙 사본 — 항상 동기화.

## 디자인 결정 (2026-07-14 사용자 ruling)

- 사용자: "배경 없이 아이콘만 있는 게 깔끔" → "아이콘 자체를 크게 만들면 되잖아. 배경이 필요 없게" + 간소화 선택.
- 결정: **full-bleed 책 디자인** — 책 표지가 캔버스 전체를 채워 별도 배경 rect가 존재하지 않음 (책이 곧 타일). 투명 픽셀이 없으므로 iOS 검정-채움·Android 크롭 제약을 자연 충족하면서 "배경 없음"의 시각 효과를 얻는다.
- 간소화: 책장·액자·리본 등 잔디테일 제거, 갈색 표지 + 중앙 금색 십자가 + 금색 책배 스트립만 유지.

## 변경 시 반드시 따라오는 것

- `public/` 자산 내용 변경 → `public/sw.js` `CACHE_VERSION` bump (구 아이콘이 cache-first로 무한 서빙되는 것 방지).
- 시각 검증은 소형 크기(48/32px) 렌더 + 원형 크롭 시뮬레이션 + 알파 채널 부재 확인까지 포함해야 함 — 512px 미리보기만으로는 홈 화면 실패 모드(십자가 클리핑, 검정 타일)를 못 잡는다.
