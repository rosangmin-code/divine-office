## 의도된 동작 (GILH 시간경별 — 시간전례 총지침 §225–229)

대축일(Их баяр) 시편 출처는 **시간경마다 다르다**:

| 시간경 | GILH | 시편 출처 |
|---|---|---|
| 제1저녁기도 (First Vespers) | §226 | **Laudate 시편** (Ps 113·117·135·146·147A·147B 중 2개) + 신약 찬가 |
| 아침기도 (Lauds) | §227 | **제1주간 주일** 시편/찬가 |
| 독서기도 | §228 | 고유(proper) |
| 낮기도 | §229 | 오름 시편(Gradual); 주일이면 제1주간 주일 |
| 제2저녁기도 (2nd Vespers) | §226 | 고유(proper) |

"제1주간 주일"은 **아침기도(§227) 전용** 규정이며 대축일 전체 규정이 아니다. 몽골어 책은 **발췌판**이라 대축일 시편을 인쇄하지 않고 완전판/GILH에 위임한다(`parsed_data/full_pdf.txt:18894-18901`, `:27931-27937`). 따라서 GILH 규정대로 채우는 것이 곧 책 재현이며, #150(책 충실)과 충돌하지 않는다.

## 현재 동작 (버그)

- **아침기도**: 가동 대축일 6개(승천·성령강림·삼위일체·성체·성심·그리스도왕)는 제1주간 주일 `psalterRef` 치환으로 §227 충족. **고정 대축일 7개**(03-19·03-25·06-24·06-29·08-15·11-01·12-08)는 `psalterRef` 부재 → **평일 시편으로 잘못 렌더**(`solemnities.json` lauds 블록 `null`).
- **제1저녁**: Trinity는 제1주간 주일 제1저녁(Ps141/142/Phil2)을 inline 복사한 **오배선**(`ordinary-time.json:3470-3525`). 나머지는 inline 부재로 평일 폴백. 성령강림만 고유 Laudate 보유(올바름).
- **제2저녁**: 7개 고정 대축일은 평일 폴백.

## 가용성 (감사 결론)

- **아침기도 §227**: 제1주간 주일 데이터(Ps63/Dan3/Ps149 + 후렴) **존재** → 7개 고정 대축일 교정 무블로커.
- **제1저녁 Laudate §226 / 제2저녁 고유 §226**: 각 대축일 고유 **몽골어 후렴이 프로젝트에 부재**하고 §226 공통 후렴 목록도 부재 → **BLOCKED**(완전판 몽골어 기도서/Ordo 필요). 시편 본문은 로컬에 있음.

## 정책 — 출처 부재 시 평일 폴백 (USER DECISION 2026-06-08)

> "없는 건 그냥 평일 기도문으로 해. 지침과 설명도 포함해주고."

- **있는 것(아침기도 §227 제1주간 주일)** → 제대로 교정(제1주간 주일).
- **없는 것(제1저녁 Laudate·제2저녁 고유의 몽골어 후렴)** → **fabricate/MT 금지**, **평일(running 4주 시편집) 기도문으로 폴백** + **루브릭 notice + 설명** 표시(고유 시편이 완전판에 있으며 여기서는 평일로 대체함을 사용자에게 투명하게 알림). 루브릭은 기존 'solemnity psalter-fallback notice'(#48 `d96b5ab`) 재사용; 신규 몽골어 필요 시 리더 백스톱.
