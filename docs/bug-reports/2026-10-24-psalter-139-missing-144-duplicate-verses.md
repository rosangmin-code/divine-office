## 1. 시편 139 제2부 — 13–18절(11행)이 통째로 없다

제4주간 수요일 저녁기도의 시편 139 는 책에서 두 부분으로 나뉜다. 제1부는 1–12절(p.464–465)이고, 제2부(p.466)는 **13–18절에 이어 23–24절**이다. 앱은 제2부를 `Psalm 139:23-24` 키로 갖고 있어서 23–24절 4행만 나온다.

```

    'Миний дотор хөнөөлт зам буй эсэхийг харж,',

책 p.466(2026-10-19 개정판 추출 텍스트) — 제2부는 13절로 시작한다:

```
II Учир нь Та гэдэс дотрыг минь хэлбэржүүлж Эхийн минь хэвлийд намайг бүрдүүлжээ. …
… Аяа Тэнгэрбурхан, надад хандсан бодлууд тань хэчнээн нандин бэ! Нийлбэр нь хэчнээн их вэ!
Би тэдгээрийг тоолбол тэд элсний ширхгээс ч даван гарна. Сэрэхдээ ч би Тантай хамт билээ.
Аяа, Тэнгэрбурхан, намайг судлан зүрхийг минь мэдээч.

이름이 `Psalm 139:1-18` 인 키도 실제로는 1–12절(27행, 마지막 행 `Гэрэл харанхуй хоёр хоёулаа адилхан юм.`)만 담고 있다. 13–18절은 앱 어디에도 없다.

## 2. 시편 144 — 제4주간 목요일 저녁기도에서 9–10절이 두 번 나온다

시편 144 는 두 곳에 쓰인다.

| 자리 | 책 | 앱 키 |
|---|---|---|
| 제4주간 화요일 아침기도 | p.444–445, `Дуулал 144:1-10` (1–10절) | `Psalm 144:1-10` ✅ |
| 제4주간 목요일 저녁기도 I | p.480–481, 1–8절 (`…Баруун гар нь худлын баруун гар юм.` 에서 끝) | `Psalm 144:1-10` ❌ 9–10절이 더 붙음 |
| 제4주간 목요일 저녁기도 II | p.481–482, 9–15절 (`II Аяа Тэнгэрбурхан, би Танд шинэ дуу дуулна.` 로 시작) | `Psalm 144:11-15` (내용은 9–15절, 키 이름만 틀림) |

목요일에는 제1부가 화요일 키(1–10절)를 그대로 쓰므로 9–10절 4행이 제1부 끝과 제2부 처음에 두 번 찍힌다.

프로덕션(2026-10-24 실측, 2026-11-12 = 제4주간 목요일). `<script>`(RSC 페이로드)를 뺀 화면 텍스트만 셈:

```

буруугийн илднээс    2   ← 10절, 한 번이어야 함
Гарыг минь дайтахад  1   ← 1절

## 3. 수정

재현 자료: `docs/research/psalter-139-144-verses/` (`emit-lines.py` → `build.mjs`, `fix-ps101.mjs`). 행 추출기는 2026-08-08 분할 시편 II부 작업의 것을 그대로 쓰고, 먼저 저장된 엔트리를 재현하는지 봤다 — 시편 139 I부 30행 전부 일치, 시편 144 II부는 책의 `II` 표지 한 행과 앱이 일부러 넣는 «Аяа,» 쉼표(STC-019)만 다름. 새 구간의 글자·연 경계는 인쇄면 PNG(p.466–467, 480–481)로 대조했다.

| 키 (전 → 후) | 쓰는 곳 | 바뀐 것 |
|---|---|---|
| `Psalm 139:1-18` → `Psalm 139:1-12` | 제4주간 수 저녁 I부 | 이름(내용이 원래 1–12절). 책에 없는 I부 뒤 마침 기도 제거. 빠져 있던 연 간격 1곳(p.465 «Хэлэн дээр минь…» 앞) 추가 |
| `Psalm 139:23-24` → `Psalm 139:13-18, 23-24` | 제4주간 수 저녁 II부 | 인쇄 26행 → 논리 22행으로 새로 만듦(13–18절 복원). I부 머리말(Ром 11:34)을 복제해 두 번 나오던 것 제거 |
| `Psalm 144:1-8` 신설 | 제4주간 목 저녁 I부 | 인쇄 25행 → 논리 23행. 머리말은 화요일 것(Филиппой 4:13)이 아닌 p.480 «Гэгээн Хилайр». 마침 기도 없음 |
| `Psalm 144:11-15` → `Psalm 144:9-15` | 제4주간 목 저녁 II부 | 이름(내용이 원래 9–15절) + 책의 `II` 표지 |
| `Psalm 144:1-10` | 제4주간 화 아침 | 그대로 |

키 이름이 곧 화면 제목(`ДУУЛАЛ 139:13-18, 23-24`)이라 분할 시편 II부 5건과 같은 규약(부마다 실제 절 범위)으로 맞췄다. 책은 부가 나뉜 시편에서 머리말을 I부 앞에, 마침 기도를 II부 뒤에 한 번만 인쇄하는데, 수·목 모두 마침 기도가 두 번 나오고 있었다.

## 4. 같은 종류가 더 있을 수 있다

GOAL 106 의 절단 스윕은 "절단 0건"으로 끝났지만 검출기 한계로 증명은 아니었다. 이번 두 건은 **키 이름의 절 범위와 실제 내용이 어긋난** 경우다(`139:1-18` 이 1–12절, `144:11-15` 가 9–15절). **겹침**(한 본문이 다른 자리에 섞여 듦)은 이번에 시간전례 단위 불변식으로 막았고 §5 의 시편 101 이 그렇게 잡혔다. **빠짐**(시편 139 처럼 절이 통째로 없는 것)은 겹침 검사로 안 잡힌다 — 시간경의 ref 마다 책 해당 쪽의 시편 첫·끝 행을 앱 엔트리의 첫·끝 행과 대조해야 전수로 찾을 수 있다(미착수).

## 5. 함께 고친 것 — 시편 101 끝에 다니엘 3 첫 연

같은 시간전례 안의 두 시편이 같은 행을 갖는지 전수로 보다가 걸렸다(이제 `split-psalm-part2.test.ts` 의 불변식). 제4주간 화요일 아침 `Psalm 101:1-8` 의 마지막 연이 같은 아침 성경찬가 `Daniel 3:26-27, 29, 34-41` 의 첫 연 4행(`Эзэн, бидний өвөг дээдсийн Тэнгэрбурхан` …)이었다. 책 p.442 의 시편 101 은 `Бүх хорон муу хүнийг устгана.` 에서 끝나고 곧바로 영광송이다.

```
