# 시편 머리말 — 64자리 없음, II부 3곳 복제, 인쇄본마다 다른 머리말을 하나로 보여 줌

- **발견**: 2026-10-27, 시편 본문 전수 대조(`2026-10-27-psalm-omission-audit.md` §7-2) 중. 남은 작업 1번 (사용자 지시 "1번 진행해"). 그 보고서의 "130곳 중 65곳"은 부 표지 «I» 를 넘지 못한 첫 집계였고, 이번 대조로 다시 세면 책이 머리말을 싣는 자리 144곳 중 64곳에 앱 머리말이 없었다
- **상태**: 수정 완료. 제목(빨간 부제) 차이는 남음 (§6)
- **영향**: 머리말 = 시편 제목 아래의 이탤릭 인용 + 출처, 예: «Надаас сур. Би дөлгөөн, зүрхэндээ даруу (Матай 11:29).» 제1~4주간 시편집 아침·저녁기도, 끝기도 시편 전부, 주일 제1저녁기도

## 1. 방법

`docs/research/psalm-header-audit/` — 본문 대조와 같은 인쇄면 행 스트림·본문 블록에서, 본문 첫 행 위의 이탤릭·출처 행을 모아 자리마다 책 머리말을 얻고 앱이 그 자리에 보여 주는 머리말과 비교했다(195자리 = 시편·찬가 191 + 초대송 4). 새로 넣는 머리말 65개는 인쇄면 PNG 로 글자를 대조했다.

## 2. 결과

```
$ python3 docs/research/psalm-header-audit/audit_headers.py /tmp/stream.json
```

## 3. 어긋났던 것

**머리말 없음 — 64자리, 본문 55개.** 대부분 찬가와 다음 시편이다.
- 찬가: 다니엘 3장 세 본문(57-88·52-57·26-41), 이사야 2·12·26·33·38·40·42·45·61·66, 예레미야 14·31, 신명기 32, 탈출기 15, 토빗 13 두 곳, 유딧 16, 시락 36, 지혜 9, 하바쿡 3, 사무엘 상 2, 역대기 상 29, 에제키엘 36
- 시편: 4·5·15·16(끝기도)·19·21·24·31·77·86·88·91·92·96·97·98·99·100·110·115·126·127·130·131·134·137·138·142·147:1-11
- 끝기도 시편(4·134·91·86·31·130·16·88)은 기존 남은 작업 "끝기도 시편 머리말 누락"과 같다.
- 시편 110(주일 저녁 네 곳)·다니엘 3장·시편 100·92·86·130 은 같은 머리말이 두 번 이상 인쇄돼 자리 수가 본문 수보다 많다.

**분할 시편 II부에 I부 머리말 복제 — 3곳.**
- 시편 135:13-21(p.385)과 136:10-26(p.434): 책은 II부에 머리말을 싣지 않는다.
- 시편 27:7-14: 책은 II부에 **자기 머리말**을 싣는다 — p.118 «II» 바로 아래 «Зарим нь босоод, Есүсийн эсрэг хуурамчаар гэрчлэв (Марк 14:57).» 앱은 I부 것(«Одоо Тэнгэрбурхан үнэхээр миний дотор оршдог (Илчлэл 21:3)»)을 보여 주었다.

**글자가 다른 것.**
- 시편 135:1-12(p.383·428): 출처 «(харьцуул. 1 Петр 2:9)» 에서 «харьцуул.»(비교)를 빼고 «(1 Петр 2:9)» 로 보여 줌 — 직접 인용이 아니라는 표시가 사라진다.
- 시편 80: 머리말 앞에 «: ».
- 시편 146: 머리말 앞에 «аз жаргалтай болох гэдэг нь ямар утгатай вэ гэдгээ мэддэг» — 책의 세 행 제목 중 둘째·셋째 행이다. 앱 제목은 «Тэнгэрбурханд найдагчид аз жаргалтай болох нь» 로 줄어 있었다(2026-04-04 `07f9f64` 부터, 두 판의 책 모두 세 행).

**인쇄본마다 다른 머리말을 하나로 보여 준 것.** 로더가 쪽과 무관하게 첫 항목만 썼다.
- 시편 67: 제2주간 수 저녁(p.239)은 «Иймээс Тэнгэрбурханы…», 제3주간 화 아침(p.333)은 «Тэнгэрбурханы…»(«Иймээс» 없음). p.333 항목이 데이터에 있었지만 쓰이지 않았다.
- 시편 113(성탄 제1저녁 p.582, 성령강림 제1저녁 p.732)과 시편 147:12-20(성탄 제1저녁 p.584): 책은 고유부에서 이 시편들을 머리말 없이 싣는데, 시편집 쪽 머리말이 나왔다.

## 4. 원인

- 머리말 카탈로그는 `scripts/extract-psalter-headers.js` 가 `full_pdf.txt` 에서 출처 괄호를 패턴으로 찾아 만들었다(FR-160-C). 출처 이름 목록에 «Гэгээн Хилайр»·«Гэгээн Атаназ»·«Гэгээн Иреней» 가 없고, 신약 목록은 «1Кор» 처럼 붙인 꼴만 있어 책의 «1 Коринт»·«2 Коринт»·«1 Тесалоник» 을 못 찾는다. 찬가(«Магтаал» 제목)와 출처 없는 인용은 처음부터 범위 밖이었다(추적성 매트릭스 FR-160 C 행: "canticles `Магтаал` 미커버").
- 로더 `loadPsalterHeaderRich(ref)` 는 쪽을 받지 않고 `entries[0]` 을 돌려주었다. 카탈로그는 같은 시편의 인쇄본마다 항목을 따로 두었지만 첫 항목만 쓰였다.

## 5. 수정

재현 자료: `docs/research/psalm-header-audit/` (`emit-headers.py` → `header-book.json` → `build-headers.mjs --write`).

- **로더**: `loadPsalterHeaderRich(ref, page)` 로 바꿨다. 항목 하나가 인쇄본 하나다. 자리의 쪽(`PsalmEntry.page`) ±1 쪽에서 가장 가까운 항목을 고르고, 없으면 그 자리는 머리말 없음이다. ±1 은 머리말이 앞 쪽 맨 아래에 있는 경우 때문이다. `resolvePsalm` 두 return site 가 쪽을 넘긴다. 쪽 없이 부르면 예전처럼 첫 항목을 준다.
- **카탈로그** (`psalter-headers.rich.json`):
  - 항목 65개 추가 (본문 56개 — 없던 55개 + 시편 27 II부, `source: "manual"`, `evidence_line_range` 는 `full_pdf.txt` 행 번호). 출처가 없는 시편 5·147 머리말은 `uncited_caption`(시편 63·47 과 같은 꼴), 출처에 숫자가 있으면 `nt_typological`, 교부 이름이면 `patristic_preface`.
  - II부 복제 3개(27·135·136) 삭제. 시편 27 II부는 p.118 머리말 추가.
  - 시편 135 출처에 «харьцуул.» 를 살렸다. 시편 80 «: »·시편 146 제목 조각은 뺐다.
  - `unmatched` 에서 Psalm 4·134·91 을 지웠다 (이제 `refs` 에 있다).
- **시편 146 제목** (`week-4.json`): 책의 세 행대로 «Тэнгэрбурханд найдагчид аз жаргалтай болох гэдэг нь ямар утгатай вэ гэдгээ мэддэг».
- 책 글자를 그대로 둔 것: «болж,Тэнгэрбурхан»(에제키엘 36, p.507 — 쉼표 뒤 띄어쓰기 없음), «Илчлэл 15,4»(이사야 2, p.316), «Илчлэл 22, 12»(이사야 40, p.361). 오식으로 보이지만 인쇄면 그대로다(хэнбугай 선례).
