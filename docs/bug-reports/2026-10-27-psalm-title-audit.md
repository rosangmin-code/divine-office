- **발견**: 2026-10-27, 시편 머리말 대조(`2026-10-27-psalm-header-audit.md` §6) 중
- **상태**: 수정 완료 (사용자 지시 "제목 정리 진행해"). 시편 113 띄어쓰기는 사용자 결정(STC-021)
- **영향**: 제목 = «Дуулал N» 아래의 빨간 부제, 예: «Аюулын үед унших даатгал залбирал».
  - 토요일 저녁(주일 제1저녁기도)의 시편 세 개: 대림·사순·부활·연중 모든 주일.
  - 끝기도 시편 전부.
  - 분할 시편 II부 10곳.

## 1. 방법

`docs/research/psalm-header-audit/emit-titles.py` — 머리말 대조와 같은 인쇄면 행 스트림에서 «Дуулал N»·«Магтаал …» 제목 줄과 머리말(또는 본문) 사이의 빨간 행을 책 제목으로 잡았다. 화면에 나오는 것은 그 시간경이 실제로 쓰는 데이터 항목의 `title` 이므로, 자리가 아니라 **항목마다**(342개) 비교했다. 주일 제1저녁은 시기 고유부 `weeks[N].SUN.firstVespers` 의 시편 항목을 쓴다(`loth-service.ts` Path 3). 자리 단위로 묶어 보면 같은 자리를 가리키는 시편집 토요일 저녁 항목에 제목이 있어서 '있음'으로 보였다.

새로 넣는 제목 21개와 표기가 다른 제목 6개는 인쇄면 PNG 로 대조했다.

## 2. 결과

```

```

`ok~` 는 글자는 같고 띄어쓰기·문장부호·대소문자만 다른 것이다. 수정 후 16개는 모두 의도한 차이다. 시편 113 «алдрыг магтан» 15개는 STC-021, 이사야 40 «Хоньчин» 대문자 1개는 STC-009 이다.

## 4. 원인

- 주일 제1저녁 고유 시편과 끝기도 시편 항목은 처음부터 `title` 필드 없이 입력됐다.
- 시편집 토요일 저녁 항목(`week-*.json` `SAT.vespers`)에는 제목이 있다. 그러나 토요일 저녁 화면은 시기 고유부의 `firstVespers` 항목을 쓴다.
- 분할 시편 II부 항목에는 2026-04-04 첫 데이터 입력(`07f9f64`) 때 I부와 같은 제목이 들어갔다(예: `week-2.json` 월 저녁 `Psalm 45:2-10`·`Psalm 45:11-18` 모두 «Хааны хуримын магтаал»).
