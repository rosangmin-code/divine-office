# 성토요일 저녁기도 카드 누락 + 부활 대축일 제1저녁기도 오제공 (FR-175)

- **발견**: 2026-09-17, 인계 문서 §3 "2027-12-25 토요일 성탄 카드" 과제를 조사하다 같은 뿌리의 더 큰 사례로 드러남
- **영향 범위**: 매년 성토요일 + 부활 대축일 (2026-2040 스윕 기준 30일), 토요일 성탄 3일 (2027·2032·2038)
- **심각도**: P1 — 사용자 화면에서 실제로 존재하는 기도가 사라지고, 존재하지 않는 기도가 제공됨

---

## 1. 증상

### (a) 성토요일에 저녁기도·끝기도 카드가 없다

```
2026-04-04 SAT [SOLEMNITY] Дөч хоногийн цаг улирлын 6-р долоо хоног  (성토요일)
    카드=["lauds"]
    본문 /pray/2026-04-04/vespers -> 자기 것 (정상 렌더, 200)
```

카드 목록은 아침기도 하나만 보여주는데 `/pray/2026-04-04/vespers` 는 성토요일
고유 저녁기도를 정상 렌더한다. **카드↔본문 불일치** — 직접 URL 을 아는 사용자만
도달할 수 있다.

### (b) 부활 대축일이 제1저녁기도를 제공한다

```
2026-04-05 SUN 부활 대축일
    카드=["firstVespers","firstCompline","lauds","vespers","compline"]
    /pray/2026-04-05/firstVespers -> 200
```

내용은 제2저녁기도의 복제다 (backstop merge 결과). 복음찬가 후렴이 양쪽 모두
«Долоо хоногийн эхний өдөр буюу тэр өдрийн…» 로 같다.

(a) 와 (b) 는 같은 원인이다 — 카드 목록은 "내일이 제1저녁기도를 가지는가" 를
보고 오늘 저녁 카드를 자르기 때문에, (b) 의 오판이 (a) 를 만든다.

## 2. 인쇄면 근거

책 페이지 ↔ 물리 페이지: `physical = (book + 1) / 2` (물리 393 = 책 784/785).

```
$ pdftotext -f 346 -l 346 -layout public/psalter.pdf -    # 책 690/691
       ЭЗЭНИЙ АМИЛАЛТ ДАХЬ
     ДЭЭГҮҮР ӨНГӨРӨХ НЯМ ГАРАГ
      Дээгүүр өнгөрөх цаг улирлын эхлэл
                 Урих дуудлага
         Өглөөний даатгал залбирал
```

렌더한 인쇄면(200dpi)으로 확인 — 부활 대축일 구역은
**«Дээгүүр өнгөрөх цаг улирлын эхлэл» → «Урих дуудлага» → «Өглөөний даатгал
залбирал» → «Оройн даатгал залбирал»** 순이고 «1 дүгээр Оройн даатгал залбирал»
표제가 **없다**. 부활 성야가 그 자리를 차지하기 때문이다.

대조군 — 부활 제2주일(책 p.701)은 그 표제를 명시 인쇄한다:

```
$ pdftotext -f 351 -l 351 -layout public/psalter.pdf -    # 책 700/701
                 НЯМ ГАРАГ
      1 дүгээр Оройн даатгал залбирал
```

성토요일 저녁기도는 책 p.683 에 인쇄되어 있다 (인쇄면 렌더 확인):

```
$ pdftotext -f 342 -l 342 -layout public/psalter.pdf -    # 책 682/683
682   Ариун нандин гурван хоног      Ариун нандин гурван хоног   683
...
                          Оройн даатгал залбирал
                          МАГТУУ: х. 876-877.
```

데이터도 일치한다:

```
$ node -e "..."
EASTER easterSunday.SUN: ['lauds', 'vespers']          ← firstVespers 없음
LENT   w6 SAT:           ['lauds', 'vespers']          ← 성토요일 저녁기도 있음
LENT   w6 SUN:           ['vespers','lauds','vespers2','firstVespers']
```

## 3. 원인

`src/lib/loth-service.ts` 의 `hasFirstVespersAndCompline` 첫 줄:

```ts
if (dayOfWeek === 'SUN') return true
```

"주일은 언제나 제1저녁기도를 가진다" 는 단축평가다. 함수의 docstring 은 이미
여러 주일이 `firstVespers` 셀 없이 backstop merge 에만 의존한다고 적어 두었지만,
**부활 대축일은 애초에 제1저녁기도가 존재하지 않는** 경우여서 backstop 이
제2저녁기도를 복제해 버렸다.

두 번째 사례(토요일 성탄)의 원인은 `keepsSundayEveningPrayerII` 가 대림·사순·부활
**주일**만 보호하고, 토요일에 떨어진 대축일은 보호하지 않았던 것이다
(`docs/bug-reports/2026-09-16-sunday-vespers2-epiphany.md` §6 에 기존 과제로 기록).

## 4. 수정

- `hasFirstVespersAndCompline` 에 `day.romcalKey === 'easter'` 예외를 `SUN` 단축평가
  **앞**에 둔다.
- `keepsSundayEveningPrayerII` → `keepsOwnEveningPrayerII` 로 일반화하고 규칙 (b)
  "비주일 대축일 + 내일이 주님의 축일(FEAST) → 오늘 제2저녁기도 유지" 를 추가한다.
  `dayOfWeek !== 'SUN'` 이 필수다 — romcal 은 **모든 주일**을 `SOLEMNITY` 로 표시하므로
  이것이 없으면 평범한 연중 주일까지 보호돼 #240 규칙을 되돌린다.
